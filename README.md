# Splitpage downloads

This repository only hosts release builds of **Splitpage**, a two-column
visual/audio script editor with a teleprompter, review comments and a
production breakdown. The source lives in a private repository.

Get the latest version from the **Releases** page:

- `SplitpageSetup-<version>-x64.exe` for Intel/AMD Windows PCs
- `SplitpageSetup-<version>-arm64.exe` for ARM Windows PCs (Snapdragon and similar)
- `splitpage-<version>.zip`, the portable app for Windows, macOS and Linux

Installed and portable copies check this page for updates on their own.
